# geode-roll-site

Trang giới thiệu của Geode Roll (game giải đố iPhone), cùng trang Privacy và Support dùng cho App Store.
Xuất bản bằng GitHub Pages từ nhánh `main` (không dùng workflow): https://nguyenvanlamm.github.io/geode-roll-site/

- `index.html`: trang chính; `privacy.html`, `support.html`: URL khai báo trong App Store Connect.
- `robots.txt`, `sitemap.xml`, `llms.txt` và bản Markdown `*.html.md` của từng trang: cho máy tìm kiếm và bot AI. Sửa trang HTML thì sửa luôn bản `.md` và `lastmod` trong `sitemap.xml`.
- `assets/share-card.jpg` (1200×630): ảnh chia sẻ OG/Twitter, ghép từ ảnh chụp màn hình game và icon.
- Mã nguồn game: https://github.com/nguyenvanlamm/geode-roll
